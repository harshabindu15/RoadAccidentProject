# Road Accident Data Analysis System

## Project Overview
The Road Accident Data Analysis System is a web-based application developed to analyze, visualize, and manage road accident data across India, with a specific focus on Andhra Pradesh. The project aims to provide a centralized platform for understanding accident statistics, identifying accident-prone areas, analyzing accident severity, and exploring accident trends over different years.

The system features an interactive dashboard that presents accident-related information through statistical summaries, charts, tables, and filtering options, making accident data easier to understand and analyze.

## Objectives
- Analyze road accident data across different years.
- Provide insights into accident trends and patterns.
- Identify accident-prone locations and areas.
- Analyze accident severity, fatalities, and injuries.
- Provide an organized interface for viewing and searching accident records.
- Support data-driven understanding of road accident patterns.

## Key Features

### Interactive Dashboard
- Displays overall accident statistics.
- Provides accident-related summary information.
- Includes interactive visualizations and charts.
- Allows users to explore accident data through dashboard sections.

### Year-wise Accident Analysis
- Supports accident data analysis from 2011 to 2026.
- Allows users to select a specific year.
- Displays accident statistics based on the selected year.
- Helps compare accident trends across different years.

### Accident Trends
- Visualizes accident patterns over time.
- Presents year-wise accident statistics.
- Helps understand changes in accident occurrence.

### Location-wise Analysis
- Supports accident analysis across India and Andhra Pradesh.
- Provides location-based accident information.
- Helps identify areas with higher accident occurrences.

### Accident Severity Analysis
- Categorizes accidents according to severity.
- Displays accident severity statistics.
- Provides insights into accident outcomes.

### Accident Records
- Displays detailed accident records in tabular format.
- Includes accident date, time, location, vehicle type, severity, deaths, injuries, and weather conditions.
- Provides search functionality to find specific accident records.

 Data Management
- Uses MySQL to store and manage accident-related information.
- Connects the database with the Flask backend.
- Retrieves accident data dynamically for dashboard analysis.

 Technologies Used

- **Python** – Backend programming and application logic.
- **Flask** – Web application framework and API development.
- **MySQL** – Database management and storage.
- **HTML5** – Webpage structure.
- **CSS3** – Dashboard styling and responsive layout.
- **JavaScript** – Interactive dashboard functionality and dynamic data handling.
- **Chart.js** – Data visualization and interactive charts.
- **Git & GitHub** – Version control and project collaboration.

 Project Architecture

The application follows a web-based architecture consisting of three main components:

1. **Frontend:** Provides the user interface, dashboard navigation, charts, filters, and accident records.
2. **Backend:** Handles application logic, database connectivity, and API requests using Python and Flask.
3. **Database:** Stores accident records and provides the data required for analysis using MySQL.

 Project Purpose
This project demonstrates the practical application of web development, database management, and data visualization techniques in analyzing road accident data. It provides an organized and interactive platform for exploring accident statistics and understanding road accident patterns.
